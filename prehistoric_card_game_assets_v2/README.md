# Prehistoric Card Game UI Assets — v2

Отдельные графические ресурсы для существующего React Native-приложения. Пакет ориентирован на композицию последнего пользовательского скриншота: каменная игровая доска с наскальной фреской сверху и большой каменной игровой поверхностью ниже.

## Структура

- `backgrounds/` — текстура земли и размытый вариант для подложки вокруг доски.
- `boards/` — полная доска, верхняя фреска и каменная поверхность отдельными слоями.
- `avatars/` — портреты игроков без динамических имён и статусов.
- `panels/` — пустые каменные/костяные/деревянные панели и кнопочные основы.
- `cards/` — рубашки/колода и примеры лиц карт; реальные значения карт нужно рисовать динамически.
- `icons/` — отдельные игровые и системные иконки.
- `decor/` — отдельно вырезанные факел, копьё, пара костей, камни и табличка с отпечатком ладони.
- `reference/` — исходный скриншот и элементы с заранее запечёнными надписями для сравнения; не использовать как динамические UI-компоненты.

## Подключение

`assets.ts` содержит статические `require()` — Metro сможет разрешить их на этапе сборки:

```tsx
import { Image, ImageBackground } from 'react-native';
import { assets } from './assets/prehistoric_card_game_assets_v2/assets';

<ImageBackground source={assets.backgrounds_earth_rock_blurred} resizeMode="cover" style={{ flex: 1 }}>
  <Image source={assets.boards_game_board_full} resizeMode="stretch" style={{ width: '100%', aspectRatio: 966 / 600 }} />
</ImageBackground>
```

Пример только показывает способ импорта; для адаптивной раскладки лучше размещать отдельные слои (`cave_mural_header`, `stone_table_surface`, панели) абсолютным позиционированием или через flex-layout, а не растягивать весь `game_board_full`.

## Что должно оставаться кодом

Тексты, имена игроков, счётчики, текущий ход, значения/масти карт, выделение выбранной карты, интерактивные состояния и hit-area кнопок должны оставаться компонентами React Native. В каталоге `cards/` есть только визуальные референсы, а не полный набор 52 карт.

## Важное замечание по качеству

Это извлечённые из растровых атласов ассеты, а не исходные векторные/слоёные файлы. Фоны атласов были удалены алгоритмически; проверьте края прозрачности, `resizeMode` и масштабирование на целевых плотностях экранов перед релизом.
