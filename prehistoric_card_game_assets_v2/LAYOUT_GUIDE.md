# Рекомендуемая композиция экрана

Слои для повторения последнего скриншота (сверху вниз):

1. **Подложка всего экрана** — `backgrounds/earth_rock_blurred.png` как размытая каменная фактура; при необходимости использовать `earth_rock_texture.png` без blur.
2. **Игровая доска** — `boards/game_board_full.png` как готовая композиционная основа. Не накладывать поверх неё одновременно `cave_mural_header.png` и `stone_table_surface.png`: эти два файла являются альтернативными отдельными слоями для адаптивной сборки.
3. **Верхняя панель стола** — отдельные `panels/stone_header_small.png` / `stone_header_wide.png`; заголовок и номер стола рисовать текстом.
4. **Игроки** — `avatars/ivan.png`, `sebastian.png`, `gosha.png`; имена, счётчики и статусы располагать отдельными Text-компонентами, не использовать подписанные варианты из `reference/`.
5. **Карты на столе** — `cards/card_face_*_reference.png` и `cards/card_back_single.png` только как визуальные образцы; значения, масти и все состояния колоды должны формироваться игровым UI.
6. **Сообщение о ходе** — `panels/bone_frame_wide.png` или `panels/stone_header_wide.png` в роли пустой рамки, текст сообщения — поверх отдельным компонентом.
7. **Рука игрока** — веер/перекрытие карт собрать из отдельных React Native-компонентов; `reference/player_hand_reference.png` служит только образцом пропорций.
8. **Мелкий декор** — иконки, факел, копьё, кости и отпечаток ладони из `icons/` и `decor/`.

## Практические замечания

- `game_board_full.png` имеет пропорции 966×600; на узких экранах лучше переключаться на раздельные слои `cave_mural_header.png` и `stone_table_surface.png`.
- Для панелей использовать `resizeMode="stretch"` только там, где это не искажает центральную фактуру; для рамок с декором по периметру лучше подготовить 9-slice/9-patch или разложить углы и края отдельными элементами.
- Все динамические данные, selection state, активный игрок и hit-area действий остаются в игровом движке React Native.
